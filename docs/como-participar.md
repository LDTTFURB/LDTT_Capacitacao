
# Como participar

O HUB de Capacitação do LDTT reúne materiais
de estudo para interessados em desenvolver
habilidades tecnológicas.

## Como utilizar

1. Escolha uma trilha de aprendizado.
2. Estude os conteúdos na ordem recomendada.
3. Realize as atividades práticas.
4. Organize seus exercícios e projetos.
5. Acompanhe os canais oficiais do LDTT
   para informações sobre oportunidades.

## Importante

A realização das trilhas não garante ingresso
no laboratório nem aproveitamento automático
de horas de atividades complementares.

## Dúvidas

Consulte os canais institucionais do LDTT.
