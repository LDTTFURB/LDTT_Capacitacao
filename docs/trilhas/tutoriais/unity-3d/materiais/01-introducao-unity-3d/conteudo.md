# Introdução à Unity 3D

## Objetivo

Reconheça os recursos usados em projetos 3D e pratique-os em um projeto de treinamento.

## Pré-requisitos

Concluir [Introdução à Unity](../../../fundamentos-unity/materiais/04-primeira-execucao-na-unity/conteudo.md).

## O que muda em um projeto 3D

Os conceitos de cena, GameObject e componente são os mesmos. O que muda são os componentes usados com mais frequência:

| Recurso | Para que serve |
| --- | --- |
| Mesh Renderer | Componente que desenha um modelo 3D na cena. |
| Material | Define a aparência de uma superfície, como cor e textura. |
| Light | Ilumina a cena; sem luz, os objetos podem aparecer escuros. |
| Rigidbody | Aplica física 3D, como gravidade, ao objeto. |
| Collider | Define o volume usado para detectar colisões. |
| Câmera em perspectiva | Mostra a cena com profundidade: objetos distantes parecem menores. |

Não é necessário concluir o curso inteiro. Alterne os trechos que ajudam na sua tarefa com exercícios em um projeto de treinamento e combine as prioridades com a equipe.

## Prática

Em um projeto de treinamento criado com o modelo **Universal 3D**:

1. Adicione um plano como chão.
2. Adicione um cubo acima do plano, com um **Rigidbody**. O cubo já vem com um **Box Collider**.
3. Crie um material, altere a cor e aplique-o ao cubo.
4. Execute a cena e confirme que o cubo cai e para sobre o plano.
