# Introdução à Unity 2D

## Objetivo

Reconheça os recursos usados em projetos 2D e pratique-os em um projeto de treinamento.

## Pré-requisitos

Concluir [Introdução à Unity](../../../fundamentos-unity/materiais/04-primeira-execucao-na-unity/conteudo.md).

## O que muda em um projeto 2D

Os conceitos de cena, GameObject e componente são os mesmos. O que muda são os componentes usados com mais frequência:

| Recurso | Para que serve |
| --- | --- |
| Sprite | Imagem 2D usada como personagem, objeto ou cenário. |
| Sprite Renderer | Componente que desenha um sprite na cena. |
| Sorting Layer | Define qual sprite aparece na frente de outro. |
| Tilemap | Monta cenários a partir de uma grade de pequenas imagens. |
| Rigidbody 2D | Aplica física 2D, como gravidade, ao objeto. |
| Collider 2D | Define a área usada para detectar colisões. |
| Câmera ortográfica | Mostra a cena sem perspectiva: os objetos não mudam de tamanho com a distância. |

## Prática

Em um projeto de treinamento criado com o modelo **Universal 2D**:

1. Adicione um sprite como chão, com um **Box Collider 2D**.
2. Adicione um sprite como personagem, com um **Rigidbody 2D** e um **Box Collider 2D**.
3. Execute a cena e confirme que o personagem cai e para sobre o chão.
